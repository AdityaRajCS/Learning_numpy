# NumPy 100

My solutions to the [NumPy 100 exercises](https://github.com/rougier/numpy-100).

The problem statements are taken from the original NumPy 100 exercise collection.
The solutions in this folder are my own implementations while learning and
practicing NumPy.
When I couldn't solve an exercise on my own, I referred to the provided solution, 
studied the underlying NumPy concepts, and then implemented the solution myself.


## Progress

## Purpose

These exercises are used to practice and reinforce NumPy concepts, including:

- Array creation and manipulation
- Indexing and slicing
- Broadcasting
- Mathematical and statistical operations
- Random number generation
- Sorting
- Reshaping
- Matrix operations
- Other NumPy functionality

I will continue adding solutions as I work through the remaining exercises.
